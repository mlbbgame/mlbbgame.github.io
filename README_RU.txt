MLBB Game — фанатский справочник по Mobile Legends: Bang Bang

О ПРОЕКТЕ
MLBB Game — статический сайт в чёрно-красном стиле. Сайт помогает искать героев, просматривать тир-лист, изучать предметы и примеры сборок, сохранять избранное, тренировать комбо и подбирать таланты с эмблемами.

ФАЙЛЫ
- index.html — структура страниц и разделов.
- styles.css — оформление и адаптация для телефона, планшета и компьютера.
- script.js — каталог героев и предметов, фильтры, избранное, сборки, комбо и подсказки.
- talents.js и talents.css — лаборатория эмблем и талантов.
- data/hero-catalog.json и data/equipment-catalog.json — локальные резервные снимки каталогов сообщества.
- README_RU.txt — описание проекта и заметки по сопровождению.
- 404.html — фирменная страница для несуществующих адресов.
- robots.txt и sitemap.xml — базовые инструкции для поисковых роботов и карта сайта.
- favicon.svg — значок MLBB Game для вкладки браузера.

ПУБЛИКАЦИЯ
Сайт опубликован через GitHub Pages:
https://mlbbgame.github.io/

После изменений в репозитории GitHub Pages обычно обновляет сайт автоматически. Если изменения не появились, подожди несколько минут и обнови страницу. В браузере может сохраняться старая версия CSS или JavaScript; номера версий файлов в index.html помогают обновить кэш.

ИЗОБРАЖЕНИЯ И ДАННЫЕ
- Каталоги героев и предметов сначала загружаются из публичного репозитория сообщества. Если источник недоступен, сайт использует локальные резервные копии (133 записи героев и 109 записей предметов на момент создания копий).
- Резервные снимки тоже могут отставать от текущего патча. Роли и характеристики — не официальные данные MOONTON.
- Если изображение недоступно, сайт показывает запасной вариант вместо сломанного изображения.
- Сборки, тир-лист, таланты и комбо — учебные ориентиры, а не официальные рекомендации. Перед использованием сверяй навыки, предметы и их эффекты с текущей версией игры.
- Избранное хранится локально в браузере устройства и не синхронизируется между устройствами.

ПРОВЕРКА ПЕРЕД ИЗМЕНЕНИЯМИ
1. Проверь синтаксис JavaScript.
2. Убедись, что все ID, используемые скриптом, существуют в index.html.
3. Проверь ссылки меню, уникальность HTML-ID и работу фильтров.
4. Проверь изображения на телефоне и компьютере; при необходимости проверь доступность внешнего источника.
5. Проверь состояние фильтров с клавиатуры и скринридером, заголовки страниц и сообщения об отсутствии результатов.
6. После публикации проверь разделы героев, тир-листа, предметов, талантов, сборок, избранного, комбо и киберспорта.
7. Проверь 404-страницу, sitemap.xml и robots.txt после публикации.
